# 以 atop 作为唯一调查证据来源

2026-09-21，用户确认改造后的调查证据只来自 atop 输出，替代原有全量 proc/cgroup 采集与 atop 可选辅助模式。现场全量线程扫描无法在预算内覆盖业务进程，而独立 atop 采样已成功定位主要 I/O 进程，因此统一证据来源，并接受指标能力受 atop 版本和已安装插件限制的代价。

agent 仍不计算指标、不排名、不做归因，server 承担分析职责。agent 不通过额外读取 proc、sysfs 或 cgroup 文件弥补 atop 的指标缺口；不可用信息必须明确报告。固定 atop 2.7.1，使用流式 parseable 证据与 schema v2。四场景共享持续采样窗口，命令行在落盘前移除，不保存原生 raw。保留旧归档下载，缺少 atop 时仅保留诊断与查询接口。后续决策已在场景改造设计中确认。
