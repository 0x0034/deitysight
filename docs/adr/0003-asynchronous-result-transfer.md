# 本地归档完成后异步转存采集结果

2026-09-22，用户确认通过 S3 转存解决办公网无法直连线上采集结果的问题，任务仍由用户或中间 server 经 agent HTTP 接口发起，agent 负责上传并返回结果链接。

采集结果先在本地完成归档，再异步上传，采集状态与上传状态独立；上传失败保留本地归档并自动重试。这使 S3 连通性故障不改变已经取得的采集证据及采集结局，调用方仍须检查远程结果是否可用。

用户进一步确认返回默认 1 小时有效的预签名 HTTPS 下载链接，在本地结果保留期内重试，重启可继续；到期仍未成功则停止重试并按本地规则清理，接受长期上传失败可能丢失唯一副本的代价，以保持磁盘保留边界明确。远程对象由 bucket 生命周期管理，本地过期不触发远端删除。

功能默认关闭，开启后仅为新任务记录转存意图；独立单并发 worker 上传固定身份的归档对象，task 响应扩展 result.s3，本地下载及保留语义继续有效。上传成功后本地结果到期不影响任务记录有效期内签发远端链接，目标配置变化不自动迁移已有任务。
