# 区分采集子进程与被调查业务进程的控制权限

2026-09-21，用户确认允许 agent 管理自己创建的 atop 采集子进程，同时继续禁止控制被调查的业务进程。此前一律禁止进程信号，使采集超时后无法终止子进程，任务与执行器持续被占用；因此只读约束按对象区分，采集生命周期控制必须由隔离执行机制实现，不能通过整体关闭沙箱获得。

同时默认设置 ATOPACCT=''，禁止 atop 自行启用系统进程会计，并接受采样间短命进程的观测盲区。Q17 已确定专用非 root UID，内核 UID 检查隔离业务进程，保留 seccomp 与 systemd 限制；agent 和 atop 共用 1 CPU/1 GiB 预算。不得让业务复用采集账号，也不得授予 CAP_KILL。
