# 为内部 YOS 使用独立转存适配

2026-09-22，用户在真实 YOS 回归后要求兼容内部 YOS。原标准 S3 适配不能直接用于该服务：网关使用 HTTP、分配的 namespace/key 含斜线、HEAD 不返回自定义元数据、重复条件 PUT 未被拒绝，云端直链需通过网关签名接口获取。

保留 ADR-0003 的异步转存、独立任务状态、持久化意图、重试和 TTL 语义，以 `s3.provider: yos` 选择新适配，结果继续放在 result.s3。标准 S3 默认行为、旧对象名与历史目标身份保持兼容；provider 与显式 HTTP 许可纳入持久化目标身份，切换目标不会迁移已有任务。

对 ADR-0003 的 HTTPS 要求作有限扩展：YOS 仅在 allow_http=true 时允许内部 HTTP 网关，下载方仍取得并校验 COS HTTPS 链接。标准 S3 仍强制 HTTPS；TLS 校验不可关闭。YOS 使用 namespace 路由，不发送 AWS 凭据或 agent token；该方式依赖内部网关的访问边界，不声称 namespace 本身是鉴权秘密。

YOS 不能提供原子条件写保证。采用任务及 agent 身份与归档摘要共同派生的短对象名，上传前校验已有对象，上传后流式读回并核对实际字节，冲突时不覆盖。该策略适用于独立写入身份；不承诺抵御其他写入者在检查/写入之间的竞争，不复制存储身份供并行实例使用。完整读回增加网络流量，共享上传截止时间，避免只凭 HEAD 长度或 ETag 认定完整性。

采用 YOS 文档的 1G 限制保守值 1,000,000,000 字节，完整 bucket/key 保守限制 128 字节，不使用未经验证的 multipart。超限结果保留本地并报告 unavailable。任务查询按需调用网关 COS 签名接口，验证响应范围和期限后返回；不持久化签名链接，不跟随网关重定向，不删除远端完成对象。

配置契约见 [配置说明](../../configs/README.md#yos-结果转存)，回归证据见 [YOS 验证](../yos-validation.md)。
